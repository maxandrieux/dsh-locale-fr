# Glossaire FR de l'interface du DeepSeek Harness

Partagé par tous les traducteurs. Registre : interface d'application de bureau, français naturel et concis, comme
l'interface française de Claude Code (« Tapez / pour les commandes », « Ignorer les permissions », « Tâches planifiées »).

## Règles

- **Vouvoiement** à l'impératif pour les actions et consignes (« Saisissez », « Choisissez »). Jamais de tutoiement.
- **Casse de phrase** : seule la première lettre en majuscule (« Nouvelle session », pas « Nouvelle Session »).
- **Concision** : une étiquette de bouton ou de menu reste aussi courte que l'anglais, ou à peine plus. Préférer l'infinitif
  pour les boutons (« Enregistrer », « Annuler », « Ajouter un plugin »).
- **Espace insécable** (U+00A0) avant `:` `;` `!` `?` et à l'intérieur des guillemets « ». Guillemets français « » pour citer.
  Apostrophe typographique ’ autorisée mais l'apostrophe droite ' est acceptée ; rester cohérent dans un même fichier.
- **Ne jamais traduire ni modifier** : les clés JSON, les variables entre accolades (`{count}`, `{name}`…), le balisage
  (`<b>`, `**`, `` ` ``), les URL, les chemins, les noms de touches (Ctrl, Shift, Enter, Esc), les commandes (`/plan`, `npm`),
  les noms de produits et de marques (DeepSeek, DeepSeek Harness, MCP, OpenAI, GitHub, npm, pnpm, Git, Markdown, JSON, YAML).
- Une variable peut changer de place dans la phrase française, mais elle doit apparaître exactement autant de fois.
- Valeur vide en anglais → valeur vide en français.
